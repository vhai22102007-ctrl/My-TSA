Thư mục này dùng để lưu trữ ngân hàng câu hỏi ngẫu nhiên.
Các file dữ liệu môn học sẽ được lưu tại đây:
1. math.json (Ngân hàng câu hỏi Toán)
2. reading.json (Ngân hàng câu hỏi Đọc hiểu)
3. science.json (Ngân hàng câu hỏi Khoa học)

Khi giáo viên thêm, sửa hoặc xóa câu hỏi trên Web, hệ thống sẽ tự động cập nhật các file trong thư mục này.
